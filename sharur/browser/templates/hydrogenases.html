This dataset stores hydrogenase subgroup labels from an earlier classifier pass. Sharur's reconciled classifier records each call's nearest reference, catalytic-domain check, KOfam corroboration and curation reason in hydrogenase_classifications; this page draws on that table.

Classify this dataset

Dry run (reports what changes and discards its staged copy), then publish:

python scripts/classify_hydrogenases.py --db DATASET/sharur.duckdb
python scripts/classify_hydrogenases.py --db DATASET/sharur.duckdb --publish

Publishing replaces the database atomically, keeps the prior file beside it, regenerates labels for affected proteins and reseals the dataset.
